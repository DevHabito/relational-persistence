## New source and important distinctions

We chose the [Argonne Leadership Computing Facility official
Polaris job export page](https://reports.alcf.anl.gov/data/ANL-ALCF-DJC-POLARIS_20220809_20221231.html)
covering 9 August–31 December 2022, a 27,825,794-byte
uncompressed CSV in the [public data catalog](https://reports.alcf.anl.gov/data/polaris.html).

The [official data dictionary](https://reports.alcf.anl.gov/data/datadictionary/datadictionary_dim_job_composite.html)
specifies `QUEUE_NAME`, `NODES_REQUESTED`,
`QUEUED_TIMESTAMP`, `START_TIMESTAMP`,
`QUEUED_WAIT_SECONDS` and
`ELIGIBLE_WAIT_SECONDS` as distinct columns.
That is materially more promising than the missing
queue identifier in the earlier HPC2N cleaned source,
**but column definitions do not prove that the
original selected CSV actually contains usable values**.

`ELIGIBLE_WAIT_SECONDS` excludes holds and time when a job
cannot run; `QUEUED_WAIT_SECONDS` includes those periods.
Treating these as interchangeable targets would be incorrect.
Also do not use final `NODES_USED`, `EXIT_CODE`
or later `END_TIMESTAMP` as information available before
job submission.

The official catalog's **data page is not an immutable
version-pinned research object**. We record the first exact
source payload SHA-256 and final same-origin download URL
when available. If the official page exposes no unambiguous
source link, the preregistered result is
`SOURCE_ACCESS_BLOCKED`, not permission to use any mirror.

## Frozen eligibility result gate

Independent CSV parsers must agree on all row widths and
count. The 27,825,794-byte CSV length must match the catalog.
The source must contain at least 1,000 structurally usable
queued/start jobs with positive requested nodes, valid
timestamps and **at least two distinct observed queue names**.
All duplicate IDs, invalid timestamps, missing resource
requests, documented hold/wait field inconsistencies and
source quality errors are retained. No outcome
distributions, fitted coefficients, forecaster or
held-out predictive score are computed.

The frozen outcomes are
`DATASET_SCHEMA_VERIFIED`,
`DATASET_SCHEMA_REJECTED`
or `SOURCE_ACCESS_BLOCKED`.

## Provenance and reuse obligations

If the first hosted audit is performed, an immutable
metadata-only report in `docs/results/RP-E011-D01-first-run/`
will provide the original Actions run ID and payload hash.
The complete original downloaded source remains
in a temporary Actions artifact rather than being
republished as an original Git source file. This
avoids inventing immutable provenance for a
download whose publisher did not supply a fixed
content hash in the catalog.

The original provider's mandatory citation:

> This data was generated from resources of the Argonne
> Leadership Computing Facility, which is a DOE Office
> of Science User Facility supported under Contract
> DE-AC02-06CH11357.

**Science boundary:** even a fully verified second
source is not independent *prediction evidence*.
A distinct RP-E011-P01 preregistration is required
before fitting or evaluating any wait-time model.
The negative RP-E010-P01 result remains intact
regardless of this source audit's outcome.
