# RP-U003-A01 — Exhaustive equal-edge-budget repair policies in 684 labeled toy networks

**FIRST registered verdict:
`FINITE_BENCHMARK_LOOKAHEAD_F1_ADVANTAGE_SUPPORTED`.**

The hypothesis passed its PREDECLARED, narrow directional test:
a deterministic two-step lookahead (LOOKAHEAD2) obtained
strictly more source-to-target path uptime than both
an ascending-label policy (ASC) and a fixed degree-based
policy (DEGREE), under exact shared repair budgets.

**Equally central NEGATIVE result:** the more computationally
expensive two-step lookahead DID NOT outperform the simpler
one-step task-aware greedy (GREEDY1) on the primary F1 metric.
Both exactly matched the exhaustive offline F1 envelope.
For the stronger two-disjoint-path function F2,
LOOKAHEAD2 improved on GREEDY1 and also matched the
offline F2 envelope. This is an exact finite test of
PRE-EXISTING graph restoration concepts, not a
universal law, a new mathematical theorem or a
measured biological/technological improvement.

## Why this is stronger than U001 and U002

Earlier RP-U001 and U002 used two intentionally
constructed six-node networks. Those comparisons
showed finite counterexamples to the notion that
node count alone determines service continuity,
but were NOT representative or independent
out-of-sample network tests.

RP-U003 instead includes **EVERY accepted graph**
in an exhaustively predefined, finite, LABELED
topological family; no network was selected
after inspecting a model's success. Two
independent accepted-family enumerators used
distinct generation strategies and topology
validations (combination enumeration versus
bitmask enumeration), with exact output
agreement. For source terminal 0 and target 5:

- Original six vertices `{0,...,5}`,
  exactly seven UNDIRECTED unit edges;
- excludes the direct terminal edge `(0,5)`;
- both terminal degrees equal two;
- ALL six vertices mutually connected in
  the original topology;
- all labeled graph edge subsets meeting
  the criteria included.

The resulting source is **684 labeled graphs**.
Each has FOUR distinct internal one-node
failure scenarios (`1,2,3,4`), for
**2,736 exact graph-loss scenarios**.
Six after-loss steps `t=1..6` each,
giving **16,416 exact scenario-steps PER
POLICY**. The six t=1..6 observations
are deterministic states, NOT independent
trials or real-world event samples.

Each policy undergoes the SAME internal node
loss, receives a new identity at t2 and may
add exactly one old-neighbor edge per
repair step until the neighborhood is
restored. Every graph-loss-time combination
has the SAME new-node count, live edge
count, number of links repaired and
cumulative unit edge cost under all
policies. The algorithms DIFFER only
in which old neighbor connection they
restore next.

Unmeasured resource consumption,
repair crew scheduling, actual machine
run times, hydraulic/biological
performance and information/computation
costs are NOT held equal.
The lookahead rule uses the specified
terminal path functionality and more
candidate calculations than static
degree and numeric-label controls.
It would be wrong to interpret this
as an equal-information comparison.

## Four fully frozen candidate policies

- `ASC`: restore neighbors by ascending
  arbitrary vertex label. Degree-blind
  and service-blind.
- `DEGREE`: restore the old neighbors
  by descending PRE-FAILURE graph degree;
  tie by ascending neighbor label.
  Does NOT know the terminal function.
- `GREEDY1`: try every immediately
  allowed next edge; maximize the
  function pair `(F1,F2)`
  lexicographically, tie by ascending
  neighbor label.
- `LOOKAHEAD2`: for each allowed
  next edge, also consider the BEST
  one additional edge on the following
  tick; rank by
  `(future_F1,future_F2,current_F1,current_F2)`,
  tie by ascending label. This is a
  disclosed, task-aware planning
  algorithm, NOT a learned controller
  or a new principle of resilience.

The independent benchmark also computed
for EACH fixed scenario/tick an
`OFFLINE_F1_ENVELOPE` and
`OFFLINE_F2_ENVELOPE`: exhaustive
maxima over all subsets of exactly the
registered number of restored incident
edges. These are separate function-specific
optimistic comparison envelopes using
all the original model structure,
NOT deployed policies and NOT
an observed real-world forecasting
baseline. No candidate exceeded them.

## Primary F1 result — at least ONE terminal route

| Policy | F1-preserved scenario-steps / 16,416 | Regret to the offline F1 envelope |
|---|---:|---:|
| ASC | **15,736** | 152 |
| DEGREE | **15,748** | 140 |
| GREEDY1 | **15,888** | **0** |
| LOOKAHEAD2 | **15,888** | **0** |
| OFFLINE_F1_ENVELOPE | **15,888** | 0 by definition |

The registered primary H1 asked whether
LOOKAHEAD2 STRICTLY outperformed BOTH
ASC and DEGREE on aggregate F1 uptime,
with the same repair budgets. It did:
LOOKAHEAD2 gained exactly **152**
scenario-steps over ASC and **140**
over DEGREE.

However **LOOKAHEAD2 and GREEDY1
TIED EXACTLY** in the total F1 count,
and both exactly attained the optimal
per-step F1 envelope for the frozen
finite population. Consequently
there is NO evidence that the extra
one-step horizon adds *F1 value* over
the simpler task-aware greedy baseline
here. Any statement that "two-step
anticipation is generally better at
restoring basic connectivity" would
be unsupported.

**All paired-case differences were
retained**, not only policy wins:
LOOKAHEAD2 vs ASC:
120 wins, **2,616 ties, 0 losses**.
LOOKAHEAD2 vs DEGREE:
116 wins, **2,620 ties, 0 losses**.
LOOKAHEAD2 vs GREEDY1:
0 wins, **2,736 ties, 0 losses**.
The original study therefore has no
observed LOOKAHEAD2 F1 loss case
in this specific exhaustive family.
That should not be generalized to
other graph classes or controllers.

## Stronger F2 — TWO internally vertex-disjoint routes

| Policy | F2-preserved scenario-steps / 16,416 | Regret to offline F2 envelope |
|---|---:|---:|
| ASC | **6,980** | 988 |
| DEGREE | **7,092** | 876 |
| GREEDY1 | **7,852** | 116 |
| LOOKAHEAD2 | **7,968** | **0** |
| OFFLINE_F2_ENVELOPE | **7,968** | 0 by definition |

Here LOOKAHEAD2 delivered **116
additional scenario-steps over
GREEDY1** and matched the exhaustive
F2 function-specific envelope.
This is the secondary registered
result, not the primary H1; it must
not be silently substituted for
F1 or called a universal gain
across domains.

Both F1 and F2 measure binary
terminal path existence, not
flow capacity, stability, adaptive
regrowth, clinical safety or
ecosystem function.

## Computational work and fair interpretation

Original function candidate evaluations
reported by the source algorithm:

| Method | Candidate function evaluations |
|---|---:|
| ASC | 0 |
| DEGREE | 0 |
| GREEDY1 | **13,164** |
| LOOKAHEAD2 | **31,236** |

Zero here means the static ordering
policies make no extra candidate
F1/F2 calls; it does **NOT** mean
zero CPU runtime. One- vs two-step
search have different computational
burdens, and counting function calls
is only a crude computational effort
indicator, not a measured wallclock
or full complexity metric.

Exact F1 regret to the offline bound
is ZERO for both adaptive task-aware
rules in these 684 graphs. This
substantially limits any claim that
the new lookahead planner discovers
a gap missing from established
greedy graph restoration.

The accepted original graph degree
sequences (all six degrees sorted,
each labeled graph counted) are:

| Sorted original degree multiset | Labeled graphs |
|---|---:|
| (1,1,2,2,3,5) | 12 |
| (1,1,2,2,4,4) | 12 |
| (1,2,2,2,2,5) | 24 |
| (1,2,2,2,3,4) | 240 |
| (1,2,2,3,3,3) | 84 |
| (2,2,2,2,2,4) | 84 |
| (2,2,2,2,3,3) | 228 |

Because these graphs are LABELED,
different labelings of isomorphic
structures may appear multiple times;
their scenario-steps should never
be called independent empirical samples.
The unweighted global mean depends
on the SOURCE family and counting
convention. Selecting different
terminal roles, graph sizes, density,
direct edges, damaged nodes, restoration
costs or allowed novel edges could
change the observed ordering.

## Controls and exact validation

The reviewed Python implementation
checks EACH original graph-loss-time
snapshot by independently replaying
the repair event sequence and
constructing its permitted replacement
from the filtered original edges.
Two F1 oracles verify source-target
reachability by BFS and simple path
enumeration. Two F2 oracles verify
two internally disjoint routes by
explicit path pairs and the
single-interior-vertex cut criterion
(Menger's classical theorem,
applicable here without direct s-t
edges). Cost parity, original-node
identity loss, no extra links,
source topology integrity, source
ensemble agreement, offline upper
bounds and all 2,736 case records
are mandatory gates.

The original run showed ZERO
source/consistency/oracle/budget
errors. The first original report
also SHA-pins its entire artificial
case-level trace. No new Lean 4
theorem was written or claimed to
certify all 684 labeled graphs;
existing Lean modules passed
regression, and the finite benchmark
was computationally checked with
independent implementations.

## Existing literature versus our contribution

Network and infrastructure restoration
under costs, graph centrality and
greedy or multi-step planning
are prior art:

- Hu et al. (2016),
  [*Recovery of infrastructure networks after localised attacks*](https://doi.org/10.1038/srep24522):
  preexisting recovery strategies using
  node/network metrics and greedy rules.
- Bartolini et al. (2017),
  [*On critical service recovery after massive network failures*](https://doi.org/10.1109/TNET.2017.2688330):
  demand-oriented recovery and
  computational heuristics.
- Averbakh and Pereira (2018),
  [*Lateness Minimization in Pairwise Connectivity Restoration Problems*](https://doi.org/10.1287/ijoc.2017.0796):
  restoration ordering, limited
  construction resources and
  combinatorial optimization.
- Gao, Barzel and Barabási (2016),
  [*Universal resilience patterns in complex networks*](https://doi.org/10.1038/nature16948)
  with the
  [published erratum](https://doi.org/10.1038/nature18019):
  preexisting conditional network
  resilience modeling.

Our narrow additional scientific
artifact is a transparent
preregistered exhaustive finite
equal-EDGE-budget benchmark:
all accepted labeled graphs,
all four failures, four unretuned
policies, exactly defined
operational functions, exact
offline upper envelopes,
independent construction/oracle
regressions, a first immutable
negative-inclusive original
record and full disclosure of
strong classical control
equivalence. That by itself is
not evidence of a **new universal
mathematical relation or physical
law**.

ecological succession or

networks, stochastic hazards,
adaptive topology growth or
predictive gains on unseen
systems. The older candidate
`C=B/(I*tau)` is still
unvalidated as a physical law.
