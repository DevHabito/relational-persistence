## Interpretation: standard, observation and remaining ignorance

The established
[Parallel Workloads Archive SWF specification](https://www.cs.huji.ac.il/labs/parallel/workload/swf.html)
defines field 1 (*Job Number*) as a counter **starting from 1**.
The
[JSSPP CERIT-SC publisher description](https://jsspp.org/workload/index.php?page=cerit)
confirms that its grid job file uses an extended SWF record with
additional node, queue, qsub and GPU fields. These are **prior-work
format definitions**, not discoveries of this research project.

D03 establishes that the original publisher file contains **job ID 0
as its first record**, inconsistent with the SWF counter convention and
with D02's previously frozen `job_id > 0` gate. D03 **does not** establish
why that happened: it may not infer a publisher mistake, an internal
zero-based conversion rule, an intentional sentinel, a mislabeled
header, or an analytically ignorable row. Such explanations require
additional independent provenance. The first row is still data under
the registered reader, not retroactively a comment.

One record out of 472,400 corresponds to approximately 0.000212% of
the file, but its rarity **does not permit** retrospectively changing
D02's strict decision rule. D02 remains definitively
`DATASET_SCHEMA_REJECTED` even though the source is byte-identical
and the anomaly's position is now known.

## Boundaries and next scientific gate

- **No** model predictions, held-out labels, model refits, MAE
  comparisons, altered source selection, causal effects or physical
  persistence claims were produced in D03.
- A newly registered observational design *could* specify a defensible
  handling of this source's initial ID 0, but must describe that
  choice as **new and informed by D02/D03**, not as the original D02
  acceptance decision. It must preserve source identity and count
  all exclusions before outcome analysis.
- The source mixes shared cloud and HPC operational contexts.
  Submission-to-start queue waiting is **not** recovery time from
  the prior software intervention experiments. A future protocol
  must establish observational timing semantics, causal feature
  availability, processor/queue confounding, chronological split
  and strong per-queue historical baselines **before any new
  predictions**.
- The original **RP-E010-P01 negative** 49,995-heldout external
  observation remains a negative result. D03 cannot reverse it.
- Lean 4 rechecked the repository's **existing formal results**,
  but this source inspection adds **no new Lean theorem**.
