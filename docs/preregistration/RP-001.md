# RP-001 — Does a three-variable index determine coordination persistence?

**Registered:** 2026-10-23 (initial research baseline).  
**Status:** frozen before running the RP-001 implementation.  
**Scope:** a declared discrete-time consensus model, not a universal test of physics.  
**Outcome:** pending at registration; see `docs/results/RP-001.md` after execution.

## Research question

Can two connected undirected networks with the same number of nodes, edges, update capacity, injected noise variance, and response latency nevertheless have different rates of return to a coordinated state?

## Models and inputs (not fit from outcomes)

- Network A: undirected path on six vertices, `P6`.
- Network B: undirected star on six vertices, `S6`.
- Edges: five in each; graph topology is the sole intentionally varied network property.
- Dynamics: `x[t+1] = (Identity - alpha * L) x[t] + xi[t]`, combinatorial Laplacian `L`.
- `alpha = 0.1`; same fixed rate for both networks.
- Capacity proxy `B = 1 update per discrete step`; latency proxy `tau = 1 step`.
- Per-vertex independent centered disturbance variance `I = 0.01` (used only in stationary-noise outcome).
- Scalar candidate: `C = B/(I*tau) = 100`, by explicit operational convention; dimensions are not claimed universal.
- Deterministic outcome: `r20 = sup_{x0 orthogonal to all-ones, ||x0||=1} ||(Identity-alpha*L)^20 x0||`.
- Stochastic outcome: expected stationary **sum** of squared deviations from the network mean under independent additive noise with covariance `I*Identity`. This exists only if all non-consensus eigenmodes contract strictly.
- No parameter estimates, adjustable network weights, or empirical outcome proxies are permitted in this first protocol.

## Predictions and decision rule

- **H_scalar-sufficiency:** equality of `B`, `I`, and `tau` is sufficient to determine the persistence outcome. Prediction: `abs(r20_path-r20_star) < 0.05`.
- **H_structural:** topology can affect persistence under fixed `B`, `I`, and `tau`. Prediction: `r20_path-r20_star >= 0.05`.
- **X:** if `abs(diff) < 0.05`, this case does *not* challenge the scalar-sufficiency claim at the predeclared resolution; report as inconclusive regarding universality.
- **Y:** if `abs(diff) >= 0.05`, the stated scalar-sufficiency claim fails **for this operationalization and dynamical class**. Report direction, value, spectral explanation, and limitations.
- Any algorithmic failure, disconnectedness, eigenvalue outside assumed domain, or contradictory independent implementation invalidates the computation and must be reported rather than reclassified as support.

The threshold `0.05` is a practical effect-size threshold for this exact deterministic contrast; it is not a p-value or statistical significance level. The alternate `H_structural` may fail even when scalar sufficiency is rejected.

## Negative controls and invariants

1. Relabeling vertices leaves `r20` unchanged.
2. A graph compared with itself has zero difference.
3. Both adjacency matrices are undirected simple graphs, six vertices and five edges.
4. Consensus mode eigenvalue of `L` equals zero (up to numerical error).
5. Direct 20-step matrix powering and spectral evaluation agree within `1e-10`.
6. When noise variance is doubled, stationary disagreement energy doubles; deterministic `r20` is unchanged.
7. Contrast a separate scalar AR(1) counterexample with stable coefficient 0.5 vs unstable coefficient 1.1 using equal externally declared proxies: this is an illustration, **not** a test of a fitted physical model.

## Interpretation boundaries

This protocol is a structural stress test. It does not falsify all meanings of relational persistence, the RZS program, or the Precategorical Modal Field Framework; those programs have more claims than the scalar formula. We will not assert novelty of consensus spectral theory. We will not call numerical consistency empirical validation. In particular, `I` is a noise variance here and cannot automatically be identified with Shannon entropy or arbitrary uncertainty metrics.
