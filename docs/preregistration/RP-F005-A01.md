# RP-F005-A01 — Preregistered genuine one-step feedback delay

**Status: frozen before the RP-F005 implementation and outcome calculation.**
**Type:** exact, deterministic, dimensionless scalar feedback model and finite
two-state linear algebra; no field measurements, model fitting, or novel
stability law.

## Question

Can introducing an actual one-update-step feedback delay change the
declared closed-loop behavior from finite-step extinction to sustained,
nonzero oscillation with the same nominal feedback gain?

This **does not test the physical scalar index** `C=B/(I*tau)`.
The actual feedback delay differs between treatments: `d=0` versus
`d=1`. Claiming equal measured response latency `tau` in both cases
would be a false measurement equivalence. Only the unit update interval,
gain, initial current state and absence of external disturbance are shared.
For `d=0`, substituting a literal zero latency into that quotient would
make the candidate index undefined, not equal.

## Frozen dynamics and initial states

- Single scalar state, rational arithmetic, zero exogenous noise:
  `x[t+1]=x[t]-k*x[t-d]`.
- Feedback delay `d` is **exactly 0 or 1 integer time step**; this
  is an actual model state delay, **not** polling or timestamp metadata.
- Fixed primary gain `k=1`, identical in the two models. The primary
  current initial state is `x[0]=1`, and the delayed model has the
  necessary prehistory `x[-1]=1`. The undelayed model is initialized
  at the same current state; it does not secretly reuse `x[-1]`.
- Evaluate exact times `t=0,1,...,24`. The **registered primary**
  observation is `Y6(d)=x[6]^2/x[0]^2`, with `x[0]=1`.
  This is a dimensionless squared residual at six steps, **not**
  asymptotic physical recovery, probabilistic stationary variance,
  or RP-F004's observable.
- Registered separation:
  `Delta=Y6(1)-Y6(0)`.
  **PASS_DELAY_CHANGES_RESPONSE** exactly when `Delta>=1/2`,
  **NO_REGISTERED_SEPARATION** otherwise, provided all validation
  invariants hold. An inconsistent invariant yields
  **STOP_INVALID_DELAY_MODEL** (do not repair by retuning).
- Additional prespecified diagnostic times `t=12` and `t=24`
  and prespecified *secondary* gains `k=1/2` and `k=3/2` are
  negative/contrast controls only, not alternative primary outcomes.
  Their values must be archived regardless of the primary result.

## Registered methods and validation

**Method A:** a scalar difference-equation iterator using `Fraction`,
carrying prehistory explicitly for delay 1. Its index maps exactly to
`x[-1],x[0],x[1],...` and never interpolates missing state.

**Method B:** an independent exact integer/rational companion-matrix
implementation. For delay 1 define the two-state vector
`(x[t],x[t-1])` and transition
`A(k)=[[1,-k],[1,0]]`; for delay 0 define
`W(k)=[1-k]`. Compute powers independently by exact
matrix multiplication. Compare **all** times `0...24` for
all three registered gains and both delays, not just the final
numbers. Report the complete paths and exact fractions.

**Controls and stop conditions:**

1. Verify that at the registered gain `k=1`, the delayed
   matrix satisfies **exactly** `A(1)^3=-Id` and
   `A(1)^6=Id`, and the undelayed factor `1-k=0`.
2. Verify the companion matrix determinant equals `k`
   for all three prespecified gains and the integer step
   conserves the specified two-state time indexing.
3. At `k=1`, starting at `x[-1]=x[0]=1`, the six-step
   delayed pair returns to its initial pair; the resulting
   periodicity is exact, not numerical near-periodicity.
4. A deterministic relabeling of the two companion-state
   coordinates must give the same primary trajectory after
   conjugating the transition matrix and initial state.
5. Reject fractional/negative delays, altered gains, changed
   prehistory, different or zero primary `x[0]`, missing
   trajectory entries, and altered matrix entries. Corrupted
   inputs must fail tests rather than be silently corrected.
6. Record the original immutable protocol SHA, the generated
   JSON, a human-readable interpretation, exact regression
   outputs, environment versions, and any CI failures.
   Do not claim formal or empirical confirmation from a
   mere printed result.

## Lean 4 formal scope

Over **real** states, formalize the gain-one delay-one map
`(current,previous) -> (current-previous,current)`.
Prove `A^6=Id` for **every** real pair, including states not
enumerated by the program. Prove that the undelayed gain-one
update maps every real initial state to zero in one step.
Prove the primary witness `x[0]=x[-1]=1` has delayed
six-step current state one and undelayed six-step state zero.
Prove there cannot exist a universal strict six-step squared
energy contraction factor `q<1` over all nonzero
two-component real delayed states, using an explicit witness.

No `sorry`, `admit`, or unsupported axioms. Such proofs
establish exact real *finite-dimensional algebra*, not
a general Schur-stability theorem, all delays, noisy
systems, empirical behavior or the PMFF/RZS bridge.

## Limitations and attribution

The example is intentionally analytically transparent. The
candidate outcome is already foreseeable from classical
linear difference-equation control theory; successful
preregistration is protection against retuning, not evidence
of surprising predictive discovery. Only the declared model
and initial condition are tested. The exact six-step identity
can be generalized algebraically within this specific gain,
but not to arbitrary `k` or arbitrary delays without proof.

Existing work includes Shin, Miyazaki & Kim (2023),
"Stability regions of discrete linear periodic systems with
delayed feedback controls",
https://doi.org/10.1186/s13662-023-03781-5,
and classical Jury/Schur stability criteria.
Classifying this finite constructive test as a new law would
misattribute established mathematics.

**Stop before declaring success** if either independent
implementation, a declared gate, a rational result,
or an asserted Lean theorem fails. Preserve failures.
