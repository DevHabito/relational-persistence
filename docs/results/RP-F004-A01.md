# RP-F004-A01 — Temporal correlation with equal noise marginals

**Registered deterministic decision: PASS_CORRELATION_MATTERS.**

This decision applies only to the explicitly declared dimensionless
linear system with symmetric two-state Markov disturbances. The scalar
proxy `C=100` is **identically assigned**, not measured. Nothing in this
result supports a new physical law or validates an observed recovery
predictor.

## Preregistration and model

The [frozen preregistration](../preregistration/RP-F004-A01.md)
was published on `main` at
[commit `1ef4370`](https://github.com/DevHabito/relational-persistence/commit/1ef43702931de3498d8cd9218563fa276b3dc3aa),
before the RP-F004 executable experiment or tests. The choice
`a=1/2`, `p∈{1/2,3/4}`, and illustrative separation threshold
`1/200` was motivated by elementary **existing** time-series
mathematics, not chosen blindly. This registration is a defense
against later retuning, not an independent priority or prediction claim.

For both conditions,

```text
x[t+1] = x[t]/2 + eta[t]
x[0] = 0
eta[t] belongs to {-1/10,+1/10}, each with marginal probability 1/2.
B=1, I=1/100 (noise marginal variance), tau=1, C=100 (assigned proxies).
```

The only change is the symmetric noise-sign Markov persistence:
`p=P(eta[t+1]=eta[t])`, comparing `p=1/2` against `p=3/4`.
Both processes start with the stationary symmetric sign law; their
one-time noise means and variances are equal, although their temporal
joint distributions differ. The noise autocorrelation at lag one is
`r=2p-1`, hence `0` vs `1/2`.

The target `Y` is the limiting **output variance**
`lim[t→∞] E[x[t]^2]`, not an observed field recovery time,
survival probability, or RP-001 graph residual.

## Exact mathematical derivation

Write `s²=1/100`, `a=1/2`,
`v_t=E[x_t²]`, and `c_t=E[x_t eta_t]`.
By construction,

```text
E[eta[t+1] | eta[t]] = r*eta[t]
v[t+1] = a²*v[t] + 2*a*c[t] + s²
c[t+1] = r*(a*c[t] + s²)
v[0] = c[0] = 0
```

The terms `c_t` **cannot be dropped** for temporally correlated
disturbances, unlike a white-noise recurrence. Because
`|a²|=1/4<1` and `|ar|≤1/4<1` for the two chosen cases,
`c_t` converges geometrically, and the forced `v_t` recurrence
also converges to its unique fixed point. This proves existence
of the asymptotic second moments within the declared model.
The fixed-point equations yield

```text
c* = r*s² / (1-a*r)
v* = (s²+2*a*c*) / (1-a²)
   = s²*(1+a*r) / ((1-a²)*(1-a*r)).
```

The formulas are classical moment algebra, not a newly
discovered stability theorem.

| Exact quantity | Independent signs (`p=1/2`) | Persistent signs (`p=3/4`) |
|---|---:|---:|
| One-time noise variance `s²` | `1/100` | `1/100` |
| Lag-one correlation `r` | `0` | `1/2` |
| Stationary cross-covariance `c*` | `0` | `1/150` |
| Limiting output variance `v*` | **`1/75`** | **`1/45`** |
| Exact 12-step output variance | `1118481/83886080` | `9320667/419430400` |

The primary difference is **`2/225`**, approximately
`0.008888888888889`, above the frozen `1/200` threshold.
The persistent-input output variance is exactly **5/3 times** the
independent-input value, an increase of 2/3. No inference about
population effect sizes or sampling uncertainty follows.

## Exact oracle and regression controls

[The executable](../../experiments/rp_f004_temporal_correlation.py)
uses only Python standard-library rational arithmetic. It computes
the fixed points from exact moment equations. Separately, a
full-path enumerator calculates each of the **4,096** twelve-step
sign histories and weights it by the initial stationary sign
probability and all eleven transition probabilities.

The exact probability masses sum to **1** for each model.
This independent path enumeration obtains exactly the same
twelve-step variance as the moment recurrence in both cases.
The 40-step moment trace, full exact fractions, and explicitly
labeled decimal approximations are committed in
[the results JSON](RP-F004-A01.json).

[Adversarial tests](../../tests/test_rp_f004_temporal_correlation.py)
reject invalid or nonregistered transition probabilities,
floating-point probabilities, altered noise magnitudes or
stationary sign weights, transition rows not summing to one,
modified enumeration horizons and incorrect moment limits.
The committed results are also checked against a fresh exact
evaluation; no post-result parameter fitting takes place.

## Interpretation and prior work

The example demonstrates **nonidentifiability of limiting output
variance from the chosen scalar inputs** in a restricted,
fully specified stochastic model. Equal marginal noise
variance is not equal process noise. It does not show that
all temporal correlations increase variance, or that the
particular index fails every conceivable operationalization;
using autocorrelation as an additional proxy would define
a different, testable model.

The underlying mathematics is established AR(1)/Markov and
second-moment state-space theory. See [Penn State STAT 510](https://online.stat.psu.edu/stat510/Lesson01),
[Manuel Arellano, *Time Series*](https://www.cemfi.es/~arellano/Time-Series.pdf),
and the [prior-work ledger](../literature/PRIOR_WORK.md).
These sources support the methodological context; they are not
claimed to contain this repository's exact frozen example.

**No real trajectories, hardware measurements, independent
physical noise calibration, held-out field test, or PMFF/RZS
derivation are supplied.** Real-world identification of
`B`, `I`, `tau`, `Y`, correlation and confounding is
still an open problem.
