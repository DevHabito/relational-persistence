## Frozen acquisition and interpretation

- HTTPS only, exact host `jsspp.org`, exact
  URL above; no credentials; downloads capped
  at **150,000,000 bytes** including the sentinel.
  The provider currently advertises a SWF download
  but its HTTP `Content-Type` could be generic or
  mistaken. Treat bytes as SWF only if their
  **content** is actually decodable SWF text,
  not because a server label resembles a format.
- Parse comments starting `;`, blank lines, and
  noncomment job records in full; preserve source
  byte SHA-256 and first 10 structural error
  line numbers in the summary. No raw job-user/
  command text in the permanent repository.
- Parse source lines with TWO independent methods:
  (`shlex.split` respecting quoted extension values)
  and a separate whitespace-token/raw SWF prefix
  validator for the first **18 standard columns**.
  Require these separate calculations to agree
  on total data records and valid numeric prefixes.
  A 19–22-column extension with quoted qsub
  arguments may be preserved without inventing
  a queue label from an absent field.
- Base SWF positions: job ID (1), submit (2),
  wait (3), runtime (4), allocated processors
  (5), requested processors (8), status (11),
  queue number (15), all 1-indexed.
  Extra fields, **IF truly present in the
  publisher's documented order**, are
  execution nodes at index 19, **queue name
  at index 20**, qsub arguments at index 21,
  requested GPUs at index 22. An actual
  unambiguous queue-name value is required,
  and must not be imputed from the old
  `queue number` field or a filename.
- Keep missing/-1 numerical values as missing.
  Count lines with no valid numeric submit/wait,
  nonpositive allocations and requests, unknown
  status, absent queue label, and duplicate job IDs.
  Do NOT drop outliers, fit a waiting time model,
  score holdout predictions or choose time windows.

## Frozen outcome gate, source-only

- `DATASET_SCHEMA_VERIFIED` iff direct provider
  source downloaded within size cap and was
  valid UTF-8 text, both SWF oracles agreed on
  total numeric-prefix-valid row counts,
  **no** duplicate positive job IDs or
  structural unparseable 18-field SWF prefixes,
  there were at least **1,000** rows with
  nonnegative submit/wait/runtime and
  positive allocated/requested processors,
  and at least **two distinct nonempty
  documented extended queue names** appear
  among such rows.
- `DATASET_SCHEMA_REJECTED` if retrieved source
  violates these exact structural gates,
  or cannot reliably identify queue-name
  extensions; preserve exact anomaly counts.
- `SOURCE_ACCESS_BLOCKED` if the exact source
  URI cannot be obtained or is off-origin,
  exceeds byte limit, or returns no data.
  Do not fabricate download contents.

A valid negative/blocked result is to be
archived as it occurred. Never re-run to
replace the first source evidence.
