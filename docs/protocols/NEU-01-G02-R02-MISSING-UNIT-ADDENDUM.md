## Why this is necessary

In [failed first Actions run #42637541779](https://github.com/DevHabito/relational-persistence/actions/runs/42637541779), **16 synthetic/adversarial preflight tests passed**. The original EEG header source was downloaded/verified, but the code returned `INSTRUMENT_FAILURE` with `CHANNEL_SCALING_OR_UNIT_UNSPECIFIED` because at least one `[Channel Infos]` entry did **not contain four comma-separated name/reference/resolution/unit fields**. The script therefore **stopped before decoding, memmapping or inspecting ANY original EEG amplitude**. An apparent numerical success from that attempt would be false.

The *first attempt* demanded full original physical scaling and units even for checks whose truth is invariant to a **fixed, nonzero** channel rescaling (NaN/Inf counts, exact adjacent equality, exact constant epochs and within-channel relative >10× PTP ratios). This amendment defines a **strictly weaker, technical raw-value integrity question**, explicitly refusing to make physical amplitude, scalp EEG artifact or physiological-quality claims. Not all metrics are scale-invariant: the prior RMS/std/PTP raw-numeric summaries will remain described as **native stored float32 units only**. Their cross-record comparison is *not* physically interpretable without verified scaling/unit and comparable processing.

## New registered guard: distinguish omitted from invalid calibration

For all 61 `Ch1…Ch61` entries in each original `.vhdr`:
- Preserve the verified channel count/name and binary layout from G01. Parse optional resolution and optional unit as **independent fields**. If absent (the source may omit trailing commas), record `MISSING`; **do not impute** `1`, `µV` or any other physical conversion.
- If declared, require resolution finite and strictly positive, else `INSTRUMENT_FAILURE`. If a unit string is declared, report the literal unit-class count (not individual channel names); missing stays `MISSING`.
- Record `header_calibration_complete` as true only if all 61 entries in **both recordings** have valid declared resolution and nonempty declared unit; if incomplete, `calibrated_physical_amplitude_ready=false` and `unit_calibration_status=NOT_ESTABLISHED`. Even if complete, source metadata alone cannot verify hardware ADC clipping or source processing.
- If a header has malformed ordinal/key/duplicate name, a changed G01 SHA-256, an incompatible binary layout, unexpected sampling, or a changed source, **fail closed**. This amendment allows only **missing optional calibration metadata**, not changed scientific endpoint/subjects or lower integrity standards.
- Run the **unchanged** complete 18,300,000-sample, 3,660 channel-epoch census exactly as predeclared in original protocol. Preserve all channels, no outcome-dependent exclusions. The frozen per-channel-median PTP >10× flag remains descriptive only.
- For internally consistent source and sample QC, decision `SOURCE_NATIVE_NUMERIC_QC_CENSUS_COMPLETE_CALIBRATION_UNVERIFIED` if any header calibration missing, or `SOURCE_SIGNAL_QC_CENSUS_COMPLETE` if fully declared. If objective sample problems (nonfinite, exact full-record flat channels or exactly constant epochs, undefined relative reference) appear, decision `SOURCE_NATIVE_NUMERIC_QC_REVIEW_REQUIRED`. **All these decisions are about source numeric QC, not certified physiological signal quality.**
- The first original failed G02 report remains attached and cited. A second original run must be separately identified as **R02-first-signal-read**, not 'first attempt'. Run full synthetic negative controls including missing unit and malformed declared scaling **before** accessing source samples. Preserve first R02 output and checksum exactly.
