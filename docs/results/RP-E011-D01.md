# RP-E011-D01 — First official Argonne source attempt was BLOCKED

**Original source-only decision: `SOURCE_ACCESS_BLOCKED`.**

[Protocol RP-E011-D01](../preregistration/RP-E011-D01.md)
was frozen on `main` in commit `0529649` before new data
acquisition. The intended source was the official
ALCF [Polaris Aug–Dec 2022 job CSV](https://reports.alcf.anl.gov/data/ANL-ALCF-DJC-POLARIS_20220809_20221231.html),
declared at 27,825,794 original uncompressed bytes,
with provider dictionary documenting queue names,
queued/start times, requested nodes and distinct
eligible/total queue-wait definitions.

The reviewed acquisition implementation was
merged in [PR #37](https://github.com/DevHabito/relational-persistence/pull/37)
at `af2f25d` after **388 Python tests per
version (3.11 and 3.12)** and a Lean 4
regression of pre-existing formal mathematics.

The **first** [hosted original run #40148017404](https://github.com/DevHabito/relational-persistence/actions/runs/40148017404)
failed to fetch the official resource page:
`Cannot access official URL: HTTPError`.
The original code did not capture the precise
status code, so do **not** invent HTTP 403/404,
resource deletion, geoblocking or maintenance as
a proven cause.

The first-run acquisition **never** downloaded
source job bytes, never counted CSV rows, never
measured queue IDs, and never computed any
forecast. The outcome is an ACCESS BLOCK,
**not a failed or successful predictive experiment**.
Both first-run JSON and its SHA-256 index
were automatically archived, without retrying
or replacing the attempt, in commit
[`4366736`](https://github.com/DevHabito/relational-persistence/commit/4366736bad06490cea4b24562768ae40aa14db18):

- [original audit](RP-E011-D01-first-run/audit.json)
- [original archival integrity manifest](RP-E011-D01-first-run/archive-index.json)

The exact first run ID and original code commit
are immutable. The original report SHA-256 is
`28bd3d11dd0fdbb9789cff251233cef468889b43bcd3942100634e73ae4a0248`.
