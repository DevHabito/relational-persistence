# Relational Persistence

*When does an organized system remain coherent as information arrives late, imperfectly, or through a limited set of relationships?*

That question is the starting point of this project. We are interested in the conditions under which a networked system preserves or recovers useful coordination while its components are perturbed. We do not begin by assuming that one formula can settle the question for every kind of system.

Relational Persistence is an open, independently reproducible mathematical and computational research program led by **Felipe Gianini Romero**. It grew out of work on the Relational Zero State (RZS) hypothesis and the [Precategorical Modal Field Framework](https://github.com/DevHabito/precategorical-modal-field-framework). These connections motivate questions; they are **not** established deductions, and this repository does not claim a new fundamental law of physics.

## Our first question

If two networks have the same update budget, injected noise variance, and response delay, must they recover from a disturbance at the same rate?

We registered an answerable version of that question **before running the computation**. The protocol fixes two six-node networks, their dynamics, a measurable outcome, and a decision threshold. The outcome is determined by an independently specified transition operator, not generated by the proposed scalar index.

Read the frozen [RP-001 preregistration](docs/preregistration/RP-001.md) before reading the [RP-001 results](docs/results/RP-001.md).

The initial scalar candidate is

\[
C=\frac{B}{I\tau}, \qquad B,I,\tau>0.
\]

We use this only as an **operational index under declared units and proxies**. It is not currently a measured physical persistence variable. In particular, calling it an identity does not make it a prediction. The first protocol tests whether these proxies alone can determine an independently computed dynamical outcome.

## What is included

- **A falsifiable protocol:** fixed hypotheses, inputs, thresholds, exclusions, and decision rules.
- **Mathematics:** a graph-consensus witness, a spectral derivation, and a separate AR(1) counterexample.
- **Computational audits:** finite-precision checks against an independent matrix-power implementation, negative controls, relabeling invariance, and boundary tests.
- **An observed network case study:** the topology of Zachary's karate club, with simulated dynamics. This is **not** a dataset of observed dynamical persistence.
- **A technical dictionary:** precise definitions, measurement status, units, and claims that are not yet justified.
- **Literature and attribution:** what follows from established mathematics, what is proposed here, and what remains unresolved.
- **A working research ledger:** failed tests and negative findings stay visible.

## Reproduce

Requires Python 3.11+.

```bash
python -m pip install -e '.[dev]'
python -m pytest -q
python -m experiments.run_rp001
python -m experiments.karate_case_study
```

The first experiment writes `docs/results/RP-001.json`. The case study writes `docs/results/KARATE-EXPLORATORY.json`. Neither script downloads data or fits its parameters to its own outcome. Environment versions are recorded in the main experiment output. On GitHub, the preregistration is preserved in [commit `d327e2c`](https://github.com/DevHabito/relational-persistence/commit/d327e2c60), before implementation commits. The original local research archive also has the tag `rp-001-preregistered`; that local tag has not been published as a GitHub tag.

## Lean 4 formal verification

The registered RP-001 **twenty-step topology contrast** is now supported by
machine-checked real-number inequalities, not only floating-point computations.
For the declared synchronous six-vertex consensus models, the path has a
mean-zero state with twenty-step Euclidean norm ratio strictly above 0.20;
the star has a uniform bound of 0.15 for **every** real mean-zero state.
Consequently, the two worst-case residuals differ by more than the
registered decision threshold of 0.05.

The proof follows the original graph update, with an explicit inverse between
six-coordinate states and `Fin 6 → ℝ`, and an identity relating coordinate
energy to the Euclidean norm. The source is in
[`RealVectorBridge.lean`](RelationalPersistence/RealVectorBridge.lean),
[`RealResidualNorm.lean`](RelationalPersistence/RealResidualNorm.lean),
[`RealGraphBridge.lean`](RelationalPersistence/RealGraphBridge.lean) and
[`RealTwentyStep.lean`](RelationalPersistence/RealTwentyStep.lean).
[Lean 4 verification #40037215631](https://github.com/DevHabito/relational-persistence/actions/runs/40037215631)
succeeded at commit `f681b973a54eb13f7260f52ecf48a228340fc124`.

The original RP-F001 certificate establishes **bounds**, not exact
spectral equalities. Subsequent [RP-F002](https://github.com/DevHabito/relational-persistence/issues/5)
work now also includes two stronger machine-checked classical results:
an explicit path mode attaining the exact ratio
`((8+sqrt(3))/10)^20` ([Lean #40040392019](https://github.com/DevHabito/relational-persistence/actions/runs/40040392019)),
and the exact supremum of achievable nonzero real star ratios,
`(9/10)^20` ([Lean #40041114514](https://github.com/DevHabito/relational-persistence/actions/runs/40041114514)).
The verified source is in [`PathSlowEigenmode.lean`](RelationalPersistence/PathSlowEigenmode.lean)
and [`StarSharpNorm.lean`](RelationalPersistence/StarSharpNorm.lean).

**RP-F002 now has a complete exact twenty-step worst-case result** for the
declared six-vertex path and star, on real mean-zero initial vectors:
`r20(P6)=((8+sqrt(3))/10)^20` and `r20(S6)=(9/10)^20`.
The new [`PathSharpSOS.lean`](RelationalPersistence/PathSharpSOS.lean)
establishes the **universal P6 upper bound** using an explicit sum of
nonnegative squares; together with the already verified attained slow
eigenmode, it proves the exact `sSup` equality.
[Lean #40042195359](https://github.com/DevHabito/relational-persistence/actions/runs/40042195359)
passed at proof commit `62bfe03e9bebd3f26ff107f206587f18c4b21e76`.
[The exact quadratic-field regression](tests/test_rp002_sos_oracle.py)
separately compares all 36 Gram-matrix entries with no floating-point
arithmetic; its [Lean and Python CI](https://github.com/DevHabito/relational-persistence/actions/runs/40042154236)
also passed.

These are machine-checked instances of **classical graph consensus and
spectral mathematics**, not a new theorem about physical persistence.
Empirical validation, domain measurements and a mathematical bridge from
PMFF remain separate open problems.

## Scientific boundaries

A classical theorem used here remains a classical theorem. A simulated signal remains simulated. A graph measured in the field does not turn hypothetical dynamics on that graph into empirical validation. A test of a special case is not a proof about nature.

The project will progress through a sequence of auditable claims rather than a sequence of impressive-sounding titles. Results that fail will remain part of the archive, including when they force us to revise the central idea.

See [research scope](docs/foundations/SCOPE.md), [model and proofs](docs/foundations/CONSENSUS_MODEL.md), [dictionary](docs/glossary/DICTIONARY.md), [literature](docs/literature/PRIOR_WORK.md), [research roadmap](docs/protocols/ROADMAP.md), and [status ledger](docs/CLAIM_LEDGER.md).

## Naming and provenance

**Relational Persistence** names a research question and a family of model-building efforts. It is not a physical law. The earlier phrase *Romero Law of Relational Stability* is retained solely where historically necessary for accurate citation. We are not silently rewriting earlier publications or pretending that a revised title changes the evidence.
