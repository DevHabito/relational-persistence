**Research track:** Functional Continuity (a NEW, separate source/model

## Motivation and known science

Natural forest canopy gaps inspired a question, NOT evidence for a new
law: can an explicitly defined system function persist after individual
components disappear, and can aggregate size/edge counts predict this?

Established ecological resilience (Holling, 1973,
https://doi.org/10.1146/annurev.es.04.110173.000245),
response diversity / functional redundancy
(Desjardins et al., 2015, https://doi.org/10.1086/681439),
and dynamical network resilience
(Gao, Barzel & Barabási, 2016,
https://doi.org/10.1038/nature16948; with
https://doi.org/10.1038/nature18019 erratum)
all PRECEDE this project. Also elementary graph paths,
vertex cut sets, and Menger's theorem are classical.
This study must NEVER call any of these concepts novel
or claim they establish a universal system law.

## Exact, completely specified six-node networks

Fixed vertices `V={0,1,2,3,4,5}`. The source terminal is
`s=0`, destination terminal `t=5`, and the FOUR
distinct removable internal vertices are
`R={1,2,3,4}`. Graphs are simple, UNDIRECTED,
unweighted, loopless. Terminal identities are fixed,
and terminal removal is NEVER allowed.

**Graph A** has exactly these seven edges (sort endpoints):
`(0,1),(1,2),(2,5),(0,3),(3,4),(4,5),(1,3)`.
It has two initially internally vertex-disjoint
source-to-target routes: 0-1-2-5 and 0-3-4-5.

**Graph B** has exactly these seven edges:
`(0,1),(0,3),(1,2),(3,2),(2,5),(2,4),(4,5)`.
All source-to-target routes cross the internal vertex 2.

Both initial graphs have six vertices, seven edges,
terminal source degree two, terminal target degree two,
all vertices initially present, and source-to-target
reachability true. Internal degrees and other structural
properties are NOT asserted matched. Graph B deliberately
has a one-vertex articulation bottleneck.

The original finite graphs were chosen to illustrate
the well-established idea that redundant paths
matter. This is a pedagogical, fully disclosed
finite **contrast**, NOT a random intervention or
novel combinatorial bound.

## Primary falsifiable question and frozen predictions

Under each removal set `S subset R` all vertices
in `S` and their incident edges are permanently
removed; NO healing, compensatory rewiring, regrowth
or later component replacement takes place. Only
the single-step terminal reachability function
`F(G,S) in {0,1}` is observed. It equals 1 iff
a path between 0 and 5 remains in `G-S`.

For a fixed `k` enumerate **ALL** `binomial(4,k)`
subsets, lexicographically; do NOT select favorable
ones. Define `continuity(G,k)=sum(F(G,S))/binomial(4,k)`.
There is NO probability distribution over real
failures; uniform subset fractions are just a
declared exhaustive toy convention.

- `k=0`: both networks 1/1.
- `k=1`: **A=4/4, B=3/4**.
  In graph B the single removal `S={2}`
  MUST interrupt the declared function;
  in graph A no one-node internal removal may do so.
- `k=2`: **A=2/6, B=2/6**.
  This is the predeclared negative control against
  making the broad claim that A is strictly more
  functionally persistent at EVERY damage level.
- `k=3`: both 0/4.
- `k=4`: both 0/1.

The study MUST FAIL its registered graph predictions
if any number above differs from either independently
calculated oracle. No hidden change to either graph
or function definition is permitted after the results.

## Structural and functional controls

- Both have exactly six initial nodes, seven edges,
  and source/target degree two. Both lose exactly
  `k` of the four removable nodes, so the
  surviving VERTEX FRACTION is identical
  `(6-k)/6` for every paired experiment.
  The remaining edges and internal degree
  distributions can be different; disclose them.
- Independent oracle A: a queue-based BFS on the
  induced surviving graph, whose input is the fixed
  edge set and removal set.
- Independent oracle B: exhaustively enumerate
  *simple* 0-to-5 paths (independent recursive
  self-avoiding path search), and flag whether at
  least one has no removed internal vertices.
  Check exact per-removal-set Boolean equality,
  not just aggregate totals. Never call the
  same BFS routine twice and claim independence.
- Implement a THIRD, small pure Lean 4 certificate
  computing the specified finite graphs and all
  four `k=1` cases, with kernel checked
  `by decide` and NO `sorry`/`admit`/`axiom`.
  The Lean certificate is restricted to the exact
  implemented Bool reachability relation and exact
  concrete graph definitions. It does NOT prove
  a universal law, real forest dynamics, or
  equivalence to every Python implementation.
- Negative control: at `k=2`, two graphs MUST
  tie exactly 2/6, so a stronger "A always wins"
  claim is rejected by the registered protocol.
- Function-definition control: `F2(G,S)` means
  *two internally vertex-disjoint source-target
  paths still exist* (rather than at least one).
  For `k=0`, graph A passes F2 but B fails.
  Under `k=1`, neither graph can meet F2
  in ANY of the four single-removal states.
  This prevents treating "continuity" as an
  undefined universal scalar independent of
  an operational function.
- Label permutation invariance: independently
  relabel the four internal vertices using
  the fixed permutation `1→3, 3→4, 4→2, 2→1`,
  fixing source and destination, and verify
  identical `k=0..4` aggregate outputs when
  corresponding removed vertex identities
  are permuted.
