# RP-F005-A01 — Exact feedback-delay contrast

**Registered deterministic decision:** `PASS_DELAY_CHANGES_RESPONSE`
for the specified gain-one scalar feedback recurrence. This is
**not** empirical stability validation, a universal law, or a
test of `B/(I*tau)`.

## Provenance and question

The [protocol](../preregistration/RP-F005-A01.md) was frozen on
`main` at [commit `1e4addb`](https://github.com/DevHabito/relational-persistence/commit/1e4addb833e12eca487cdfce7ad61ad5029213b5)
*before* the new executable test, its computations, and these
results. The model, two delays, initial states, primary gain,
secondary control gains, time horizon, observable, gate and
failure behavior were fixed beforehand.

The model is

```text
x[t+1] = x[t] - k*x[t-d]
k = 1 for the primary result
d = 0 or 1
x[0] = 1
x[-1] = 1 for d = 1
no external perturbation
```

**Critical measurement distinction:** the two cases have different
*actual* model feedback delays. Their response latencies are **not
equal**, and a purported scalar-index contrast at equal `tau`
would be invalid. In particular, zero feedback delay cannot be
substituted uncritically into the denominator of `B/(I*tau)`.
Here the scalar quotient is **not defined or tested** for either
treatment.

## Exact primary observations

At `k=1`, the undelayed state update is `x[t+1]=0`, and the
delayed state update is `x[t+1]=x[t]-x[t-1]`.

| t | Without feedback delay (`d=0`) | One-step delay (`d=1`) |
|---:|---:|---:|
| 0 | 1 | 1 |
| 1 | 0 | 0 |
| 2 | 0 | -1 |
| 3 | 0 | -1 |
| 4 | 0 | 0 |
| 5 | 0 | 1 |
| 6 | 0 | 1 |
| 12 | 0 | 1 |
| 24 | 0 | 1 |

The **preregistered** outcome is `Y6=x[6]^2/x[0]^2`,
giving exact values `Y6(0)=0`, `Y6(1)=1` and
`Delta=1`. The result is therefore above the frozen
threshold `1/2`, with no rounding and no fitted parameter.
It is a deterministic model comparison, not a statistical
claim about a population of systems.

## Algebraic explanation

At gain one, the genuine delay-one augmented state
`s[t]=(x[t],x[t-1])` obeys

```text
s[t+1] = A*s[t]
A = [[1, -1],
     [1,  0]]
A^3 = -Id
A^6 =  Id
```

This identity holds for every two-component real state, not
only the prehistory used by this experiment. Consequently
nonzero initial states in this declared model cannot have
strict uniform six-step squared-energy contraction. The
undelayed gain-one state instead vanishes in one step.

This **is not** the stability theorem for arbitrary feedback
gains, multiple delays, time-varying controllers, nonlinear
systems or physical latency measurements. It is an instance
of well-established linear difference-equation dynamics.

Those are **finite-time** values. They show that the

## Independent implementations and adversarial controls

- [Scalar history iterator](../../experiments/rp_f005_feedback_delay.py)
  uses exact `Fraction` values with the delayed prehistory
  at a separate index.
- A separate `2×2` companion matrix and `1×1` undelayed
  matrix are independently exponentiated using exact
  matrix multiplication. Both methods must agree for **all
  25 state observations**, at all three registered gains
  and both declared delays.
- The companion determinant is verified to equal `k`.
  At `k=1`, `A³=-Id` and `A⁶=Id` are checked
  exactly; a coordinate swap and conjugation must leave
  the actual trajectory unchanged.
- [Adversarial tests](../../tests/test_rp_f005_feedback_delay.py)
  reject mutated time indexing, altered prehistory or
  current initial value, unsupported delays, off-protocol
  gains, bad matrix powers and malformed matrix products.
- The [complete rational result archive](RP-F005-A01.json)
  contains every state through step 24 for all six cases.
  CI also recomputes it and compares the complete JSON
  to the committed version.

Floating-point approximation and error tolerances are
unnecessary for the scientific decision. All reported
values above are exact.

## Lean 4 validation scope

`RelationalPersistence/DelayedFeedback.lean` encodes
the delayed and undelayed operators on real states.
It aims to prove the real three-step negative-identity
component statement, real six-step identity, single-step
undelayed extinction, primary six-step separation and the
failure of uniform strict six-step energy contraction.
**The source must pass pinned Lean CI before any of these
new declarations is described as machine checked.**

The finite companion-matrix implementation is a
computational cross-check. Neither it nor the Lean
algebra supplies experimental latency measurements,
general network consensus stability or a derivation
of the PMFF/RZS primitives.

## Prior art, research scope, and next gap

Delayed feedback and Schur/Jury stability criteria are
well-established control theory, see e.g.
Shin, Miyazaki and Kim (2023),
[*Stability regions of discrete linear periodic systems
with delayed feedback controls*](https://doi.org/10.1186/s13662-023-03781-5),
and the [prior-work ledger](../literature/PRIOR_WORK.md).
The project's contribution is an explicit prospective
exact test and a scoped formal witness, **not** a
novel fundamental stability law.

The next scientifically distinct task would be to test
measured end-to-end latency, control calibration and
independent recovery outcomes under new, separately
preregistered physical instrumentation. The current
result cannot be recycled as such a test.
