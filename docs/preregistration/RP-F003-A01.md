# RP-F003-A01 — Frozen equal-degree-sequence topology test

**Status: registered before running the F003 graph enumeration or evaluating its outcomes.**
**Type:** deterministic finite-model search; no field observations, inferential p-values, or physical-law claim.

## Motivation and registered question

RP-001 compared a six-node path with a six-node star. Their different degree
sequences leave an easy local explanation for their different convergence
rates. Here we ask a stricter, finite question:

> Among *connected, simple, undirected, unweighted* graphs on six labeled
> vertices with the **same sorted degree sequence**, can the declared
> consensus model produce a difference in normalized mean-zero twenty-step
> **squared** residual of at least 1/100?

This is an **existence** question, not a typical-effect or statistical
sampling question. The graph structures are synthetic, not measured networks.
The registered observable differs from RP-001's worst-case Euclidean norm;
neither may be substituted for the other after inspecting the results.

## Fixed definitions

1. Vertices are exactly `{0,1,2,3,4,5}`. Encode each undirected edge
   `(i,j)` with `i<j` as one of 15 ordered bits, in lexicographic order:
   `(0,1),(0,2),...,(0,5),(1,2),...,(4,5)`.
   Enumerate all integer edge masks from `0` through `32767`,
   inclusive, and retain only connected graphs.
2. Group all retained masks by **sorted nondecreasing integer degree
   sequence**. Graphs within a group necessarily have the same six vertices,
   edge count and per-vertex degree multiset. Do **not** condition on graph
   isomorphism, spectrum, fitted labels, or the resulting recovery outcome.
3. Let `L=D-A`, `W=Id-L/10` and `T=20` synchronous, noise-free steps,
   with no estimated parameters. For `z_i=e_i-(1/6)1`, define

   `Q20(G) = (1/5) * sum_{i=0}^5 ||W^20 z_i||_2^2`.

   This is the mean normalized residual squared energy under the fixed
   mean-zero basis ensemble, **not** the worst-case residual or a measured
   recovery rate. Equivalently, with `Pi=Id-11^T/6`,
   `Q20=tr(Pi W^40 Pi)/5=(tr(W^40)-1)/5`.
4. Primary result is
   `Delta = max |Q20(G)-Q20(H)|` over **all pairs of connected six-node
   graphs with exactly the same sorted degree sequence**. This is an
   exhaustive deterministic maximum, not a model fit. If a degree sequence
   contains only one labeled graph, it contributes no pair.
5. **Precommitted decision:** `PASS_EQUAL_DEGREES_INSUFFICIENT` iff
   `Delta >= 1/100`. Otherwise:
   `NO_REGISTERED_SEPARATION_AT_N6`. A close or negative result is
   retained as such; do not change `T`, the graph size or the threshold.
   Threshold 1/100 is a declared design cutoff, not an estimated effect.
6. Report the maximizing pair as ordered masks `(min(mask1,mask2),
   max(mask1,mask2))`; in a tie, choose the lexicographically smallest
   ordered pair. Report both degree sequences and integer edge lists, all
   group sizes, number of connected masks, the exact rational values and
   difference, decimal approximations solely for readability.
7. Preset assigned scalar proxies `B=1,I=1/100,tau=1` are equal for
   every graph, so `C=100` by definition, but these are *not measured
   update bandwidth, noise intensity, or physical latency*. This protocol
   tests topology sufficiency even after degree-multiset matching, not the
   validity of those proxy assignments in a real system.

## Exact arithmetic and two independent computations

Use the integer matrix `M=10Id-L`, so that `W=M/10`.
Every entry of `M^20` and `M^40` is an integer. Compute the primary
`Q20` using

`Q20 = (sum_{i,j}(M^20)[i,j]^2 - 10^40)/(5*10^40)`.

All comparisons and maximum selections use integer numerators with the
same strictly positive denominator. Do not use eigenvalue solvers, machine
epsilon, numerical tolerances, or floating point in the primary decision.

Independently check the **selected extrema** by computing `M^40` with
a separate routine and verifying

`tr(M^40) = sum_{i,j}(M^20)[i,j]^2`.

This cross-check exploits symmetry but uses a separate exponent, different
summation path and a separately implemented matrix multiplication; it
cannot certify a common mistaken mathematical model.

## Preregistered controls and stopping rules

- Full exhaustive graph count must be exactly `2^15=32768`.
- Every retained graph must be connected; edge/degree counts, symmetry
  and tenfold row sums of `M` must agree with the decoded edge mask.
- `Q20` must be a nonnegative exact rational.
- Selected-mask outputs must be invariant to vertex relabeling by the
  fixed permutation `[5,4,3,2,1,0]`; degree-multiset grouping must
  also be invariant.
- For the empty graph `Q20=1` by this formula; it must be excluded
  because it is disconnected. For the complete graph `K6`,
  `W` has disagreement eigenvalue `2/5`, hence
  `Q20(K6)=(2/5)^40` exactly.
- A synthetic deliberately corrupted edge bit, unsupported graph size,
  mismatched degree signature or altered matrix entry must cause a
  regression check to fail.
- A failed invariant is `STOP_INVALID_ENUMERATION`, **not** a repaired
  positive finding. No retuning after observing a failure.
- Preserve the protocol commit, source, test execution, result document,
  exact rational values and audit constraints. New runs must keep this
  preregistration unchanged.
