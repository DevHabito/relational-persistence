## What was predicted

The target `Y` was the first **observed** empty/idle
sample after injector end, with 500 ms sustained
sampled-idle confirmation, reported in seconds.
Two independent replay algorithms matched the same
original health streams. This does not prove continuous
idleness between samples.

The forecast instant was fixed at injection end. Inputs
available by then included pretrial throughput calibration
`B` (task/s), measured accepted-work injection rate `I`
(task/s), independently timestamped service-applied
controller latency `tau` (s), and last **pre-end**
observed queue-plus-active state. Prediction fits were
trained only on the first 18 chronological trial labels.
No post-end monitor response or held-out recovery was
used to fit model coefficients.

The fitted primary index-only model used `Z=1/C=I*tau/B`
(in seconds) as its **only regressor**:

```text
Yhat_index = max(0, alpha + beta*(1/C))
alpha = 0.2099110566089991 seconds
beta  = 0.27484645083059545 (dimensionless)
```

A more complex interpretation of C, additional parameters
or a nonlinear transformation **was not evaluated**. Any
attempt to substitute such alternatives using the held-out
results requires a **new** protocol and new test data.

The primary comparators were a constant equal to the
training average (0.2893438432222222 s) and the
unfitted finite-backlog-throughput engineering heuristic
`(last_pre_end_queued + active)/(2*B)`. The latter is
**not** Little's stationary queueing theorem. Tau-only
and intended-load-only OLS were prespecified secondary
diagnostics, not post-hoc model selections.

## Original forward held-out errors (n=9)

| Preregistered model | MAE (s) | MAE (ms) | Role |
|---|---:|---:|---|
| Finite queue backlog/(2B) | **0.0111175823** | **11.118** | Primary classical comparator |
| Load-only OLS | 0.0173245342 | 17.325 | Secondary |
| Index-only `1/C` OLS | **0.0681857159** | **68.186** | **Registered proposed predictor** |
| Tau-only OLS | 0.0695156666 | 69.516 | Secondary |
| Train-average constant | 0.0724996781 | 72.500 | Primary trivial comparator |

The index is about **5.95%** better than the training
constant but about **6.13 times** the error of the
queueing comparator. It therefore fails the **frozen**
requirement to be at least 10% better than **both**:
`MAE_C <= 0.9*MAE_const` **and**
`MAE_C <= 0.9*MAE_queue`.

This is an exact evaluation of the original stored
floating-point trial measurements, not an exact rational
mathematical theorem; the decimal presentation above is
rounded. The archive retains all nine individual
observed values, predictions, absolute errors, fitted
coefficients, signed biases and original input features.
No p-value, confidence interval, population-generalizing
precision claim or model-family selection is inferred.

## Interpretive boundaries

**What this test supports:** an operational scalar built
only from measured local throughput, injection rate and
application latency was **not sufficiently predictive**
of the queue-drain recovery endpoint to outperform a
classical finite backlog comparator in this one
preregistered hosted software setting. An independently
recorded queue snapshot was a much more informative
predictor than this fitted scalar alone.

**What it cannot establish:** that every scalar extension,
every physical definition of relational persistence or
every nonlinear alternative must fail; that the
head-to-head error ratio generalizes beyond this synthetic
single-worker FIFO implementation; independent physical
hardware, unbiased population sampling, or causal
identification beyond the deliberately assigned treatments.
Two VM jobs share the source model and cloud platform;
a single nine-trial holdout does not have a scientifically
justified population effect estimate.

The existing Lean 4 proofs concern **separate exact
mathematical statements**. Lean regression passing does
not formalize software timing uncertainty, empirical
source independence or this learned prediction model.

## Next research question

This negative result provides a reason to avoid promoting
`C=B/(I*tau)` to a domain-general recovery formula.
The next scientific decision should involve reviewing
whether a well-defined vector of state, actual memory,
delays and perturbation structure has falsifiable,
noncircular predictive content **beyond existing queue
and control models**. Any newly proposed extension
must be registered before collecting *new* held-out
data. The present test observations are now part
of the development record, **not a reusable blind
test set**.

For standard prior queueing results, see
[Little (1961)](https://doi.org/10.1287/opre.9.3.383).
The specific backlog/rate predictor here is a finite
work-conservation approximation, not Little's law.
