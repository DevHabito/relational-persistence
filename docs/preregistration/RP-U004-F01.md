# RP-U004-F01 — Retrospective Boolean-objective order certificate

**Research lead:** Felipe Gianini Romero  
**Date:** 3 November 2026  
**Status:** RETROSPECTIVE proof audit of an already known mathematical limitation; NOT a blind prediction or a new original experiment.

## Why this proof is needed

In the already completed RP-U004-P01 finite graph benchmark, six named repair policies produced only four distinct repair-decision rules. In every one of the original 2,850 cases, `GREEDY_F1` and `GREEDY_F2` chose the same full repair order. The same was true for `LOOKAHEAD2_F1` and `LOOKAHEAD2_F2`.

This is not an unexplained lucky numerical match. The declared F2 task is two internally vertex-disjoint terminal routes and F1 is at least one route. By its definition, `F2 -> F1`. The only admissible Boolean function values are `(0,0)`, `(1,0)`, `(1,1)`. Swapping their lexicographic priority does not change their strict ordering. Existing finite graph and path-connectivity theory is background here, not an original mathematical discovery.

I am writing this protocol **after** the first U004 outcome and after observing the duplicated choices. It fixes the proposition to audit before I add any Lean 4 statements. Its purpose is correction of interpretation and explicit mechanical checking, not registration of a fresh hypothesis whose result is hidden.

## Fixed formal objective

Let a score be a pair `s : Bool × Bool` with `s.2 = true -> s.1 = true`. Define `f1Key(s) = 2*F1(s)+F2(s)` and `f2Key(s) = 2*F2(s)+F1(s)`, with Booleans mapped to zero/one. These numeric keys have the same order as the corresponding lexicographic Boolean priorities on the specified finite domain.

1. Prove that the nested Boolean condition admits exactly the three score pairs above.
2. For any TWO admissible scores `a,b`, prove `f1Key(a) < f1Key(b) <-> f2Key(a) < f2Key(b)`.
3. Prove equality/tie equivalence for the same pair of keys.
4. For any FOUR admissible scores representing the best next-step result and current result of two candidate first actions, prove that the lexicographic ordering of `(futureF1Key,currentF1Key)` agrees with that of `(futureF2Key,currentF2Key)`. Prove the corresponding tie criterion as appropriate.
5. Check the original finite objective-order regression in Python and keep its scope separate from the Lean theorem. The original U004 archive, all first-run checksums, case-selection criteria, and outcome verdict must not change.

The exact numeric encoding is a proof device for a tiny finite order; it is **not** a new persistence index, a physical scale or a property of non-Boolean losses.
