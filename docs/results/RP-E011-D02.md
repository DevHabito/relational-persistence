# RP-E011-D02 — New original JSSPP CERIT-SC workload source audit

**State: separately preregistered; no D02 original bytes
yet downloaded or modeled.**

The RP-E011-D01 official ALCF Polaris source attempt
had `SOURCE_ACCESS_BLOCKED` on its first GitHub-hosted
run #40148017404. That original blocked outcome
remains archived and is **not** replaced.

D02 is separately frozen by
[RP-E011-D02 preregistration](../preregistration/RP-E011-D02.md)
on `main` at `e3a2d21` **before
implementing its source parser or any D02
data acquisition**. The candidate is the
[original CERIT-SC/JSSPP 2017 mixed cloud/HPC
workload](https://jsspp.org/workload/index.php?page=cerit),
specifically the publisher's original
[grid jobs extended SWF source](https://jsspp.org/workload/logs/2017/cerit/grid-jobs.swf).

The publisher documents additional node name,
**queue name**, qsub submission argument and
requested GPU fields beyond standard 18-column SWF.
The source is NOT checksum-pinned at its
provider before acquisition. This D02 gate
will measure original full SHA256, bytes,
response URL, row count, duplicate/missing
IDs, numeric SWF prefix integrity and
genuine extended queue-name coverage.

The preregistered D02 gate requires at least
1,000 structurally eligible jobs, **two
different nonempty extended queue names**
and full agreement between independently
parsed standard SWF fields. Otherwise
an accessible but invalid source is
`DATASET_SCHEMA_REJECTED`. Failed provider
access is `SOURCE_ACCESS_BLOCKED`.
No source, code, window or criterion may
be substituted after seeing the first result.

This experiment intentionally computes
**no waiting-time predictions**, confidence
intervals, temporal trends or new Lean
theorems. Its only purpose is to establish
whether we have independently collected
production fields for a separately
preregistered queue/resource-aware
observational study.

Source acknowledgment: Dalibor Klusáček
and Boris Parák, *Analysis of Mixed Workloads
from Shared Cloud Infrastructure* (JSSPP,
2017); CERIT-SC and Czech National
Distributed Infrastructure MetaCentrum.
