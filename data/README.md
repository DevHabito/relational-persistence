# Observational data policy

No external performance measurement dataset is included yet. `networkx.karate_club_graph()` loads a bundled empirical topology from an installed library; this is an observed network, **not** an observation of our dynamical model.

A new empirical dataset requires source URL and DOI if available, acquisition date, use permission, exact checksum, missing-value policy, units, time alignment, leakage audit and predeclared independent target. Code must never replace an unavailable dataset with synthetic observations while reporting them as real.
