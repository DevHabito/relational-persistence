## Frozen observational question

At each real recorded HPC job submission, estimate its
logged submission-to-start **waiting time** (seconds)
using only already observed past job start events.

The test uses an *archive-derived aggregate waiting
job count*, **not** a directly monitored physical
queue, and compares three fixed, unfitted alternatives:

- STATIC: prior waiting-count proxy divided by
  recent observed job start throughput.
- TREND: two prior waiting-count observations
  used to extrapolate that proxy to the
  submission instant, divided by the same
  observed start throughput.
- HISTORY: moving mean observed waiting time
  of jobs started earlier (strong classical
  comparator).

The registered 70%-of-time diagnostic and
30%-of-time holdout split uses source submission
timestamp range alone. A passing result requires
TREND heldout MAE to be at least **10% less
than BOTH STATIC and HISTORY**, with valid
complete source and two independent state
reconstruction oracles.
